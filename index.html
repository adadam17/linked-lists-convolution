גרסה א: הרעיון

אסור להפוך את הרשימות, ובחד-כיוונית אי אפשר ללכת אחורה. לכן מחשבים כל ck בהדרגה: המכפלה ai·bj נכנסת ל-ci+j−1. עבור כל ai עוברים על L2 מההתחלה, ובמקביל על L3 החל מ-ci. כל המצביעים מתקדמים רק קדימה. עוצרים כשמגיעים לסוף L3. מספר המכפלות: n + (n−1) + … + 1 = n(n+1)/2, כלומר זמן ריצה Θ(n²).

ConvolutionSingly(L1, L2)
    L3 = new list of n nodes with key 0
    pa = head(L1)
    startC = head(L3)              // c_i : where a_i * b_1 goes
    while pa != NULL
        pb = head(L2)
        pc = startC
        while pc != NULL           // stop after c_n
            key(pc) = key(pc) + key(pa) * key(pb)
            pb = next(pb)
            pc = next(pc)
        pa = next(pa)
        startC = next(startC)      // a_(i+1) starts one node later
    return L3

גרסה ב: הרעיון

לכל צומת יש גם מצביע prev, ולכן אפשר לחשב כל ck ישירות לפי הנוסחה: מצביע על L1 מתקדם מ-a1, ומצביע על L2 חוזר אחורה מ-bk. מחזיקים מצביע ל-bk, שמתקדם צעד אחד בין k ל-k+1, כך שלא מחפשים אותו מחדש. זמן ריצה Θ(n²).

ConvolutionDoubly(L1, L2)
    L3 = empty list
    bk = head(L2)                  // b_k for k = 1
    while bk != NULL
        sum = 0
        pa = head(L1)
        pb = bk
        while pb != NULL           // from b_k back to b_1
            sum = sum + key(pa) * key(pb)
            pa = next(pa)
            pb = prev(pb)
        append a node with key sum at the end of L3
        bk = next(bk)
    return L3
